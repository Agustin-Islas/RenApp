# RenApp

🌐 **Landing Page:** [renapp-eight.vercel.app](https://renapp-eight.vercel.app/)

Sistema integral para registrar, consultar y acompañar el tratamiento diario de diálisis peritoneal. El proyecto combina una aplicación multiplataforma para pacientes con un panel clínico para nefrólogos.

## Misión

RenApp busca convertir el registro diario de diálisis peritoneal en una experiencia simple, trazable y clínicamente útil. La meta es que el paciente pueda cargar sus recambios sin fricción y que el doctor tenga la información ordenada para detectar atrasos, tendencias de ultrafiltración, balances anormales y necesidades de seguimiento.

El proyecto no reemplaza el criterio médico: organiza los datos, mejora la continuidad del seguimiento y prepara la base para una comunicación más fluida entre el paciente y su equipo de salud.

## Características Principales

### Para el Paciente
- **Registro Diario Simplificado:** Carga de recambios, infusiones y drenajes de forma rápida e intuitiva.
- **Historial y Tendencias:** Visualización mensual y semanal de ultrafiltraciones y balances.
- **Exportación de Reportes:** Generación automática de reportes en PDF para presentar o enviar al equipo médico.

### Para el Nefrólogo
- **Panel Clínico:** Acceso unificado a la lista de pacientes asociados.
- **Monitoreo Remoto:** Revisión detallada de los registros diarios, promedios y evolución de cada paciente.
- **Gestión Integral:** Visualización clara de los balances hídricos para facilitar la toma de decisiones clínicas informadas.
